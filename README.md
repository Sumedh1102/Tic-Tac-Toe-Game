# Tic-Tac-Toe-Game
The Tic-Tac-Toe Game is a simple C-based console application that allows two players to play the classic Tic-Tac-Toe game, taking turns to mark a 3x3 grid and determining the winner or a draw.


# Features
	•	Two-player gameplay on the same machine.
	•	Displays a 3x3 grid with numbers initially, then updates with players’ moves.
	•	Checks for a winner or a draw after every move.
	•	Simple and interactive command-line interface.

# How It Works
	1.	The game starts by displaying an empty 3x3 grid.
	2.	Players take turns to enter a number (1-9) corresponding to the grid position where they want to place their mark (X or O).
	3.	After each move, the game checks for a winner or a draw.
	4.	The game continues until a player wins or all spots are filled, resulting in a draw.

# Example Workflow
	1.	Player 1 (X) makes their move:
	•	Player 1 enters a number (e.g., 1 for the top-left corner).
	2.	Player 2 (O) makes their move:
	•	Player 2 enters a number (e.g., 5 for the center).
	3.	The game continues until there’s a winner or a draw.
